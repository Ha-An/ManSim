# ManSim v0.5 Release Notes

ManSim v0.5는 factory와 shipyard를 같은 simulation workspace에서 실행하고, HumanoidSim의 task semantics와 결합해 정책 비교, 복잡도 분석, 재현 가능한 artifact 검증을 수행하는 릴리스입니다.

## Scenario Architecture

- 기본 scenario 이름을 `factory_mfg_basic`으로 통일했습니다.
- `shipyard_basic`은 선박 외관 surface tile의 용접, 표면처리, 도장, 검사와 cart batch logistics를 모델링합니다.
- scenario plugin은 map, world, task, KPI, replay layout을 제공하고 Results Hub와 dashboard renderer는 공통으로 사용합니다.

## Decision And Dispatch

- 기본 mode는 `rolling_horizon_dedicated_roles`입니다.
- rolling horizon task는 stable top-level task id를 가지며 pool, dispatch, requeue, start, end까지 같은 id를 유지합니다.
- window boundary에서 시작하지 않은 task를 다시 ranking하고 worker는 여러 task를 FIFO queue로 받을 수 있습니다.
- urgent trigger는 현재 task를 중단하지 않고 완료 직후 실행하는 `next_after_current` 정책을 지원합니다.
- `bottleneck_aware_dispatch`는 bottleneck relief와 downstream progress를 반영해 즉시 선택합니다.
- `rolling_horizon_throughput_optimizer`는 OR-Tools CP-SAT만 사용하며 feasible solution이 없으면 fallback 없이 실패합니다.

## Humanoid Runtime

- State, Task, Primitive, Incident, Recovery protocol은 설치된 HumanoidSim catalog를 기준으로 실행합니다.
- `REPLENISH_MATERIAL`은 generic request로 생성되고 `PRIMITIVE_IDENTIFY_ITEM`에서 concrete material을 binding합니다.
- battery delivery 중 receiver는 기존 작업을 계속하고, 실제 handoff 동안만 잠시 멈춘 뒤 이전 작업으로 복귀합니다.
- battery가 이미 0인 worker의 추가 이동을 runtime과 artifact audit에서 차단합니다.

## Analysis And Visualization

- HumanoidSim primitive difficulty를 사용해 task complexity, cumulative operational complexity, OTC를 계산합니다.
- Factory Pre-Run Diagnostics는 worker burden imbalance, resource conflict potential, traffic contention, service tile scarcity, robot interaction load, power coordination risk를 실행 전에 계산합니다.
- Results Hub는 scenario와 mode를 표시하고 KPI, Gantt, Pre-Run Diagnostics, 3D Replay Studio로 연결합니다.
- manager와 knowledge 화면은 해당 기능이 실제로 활성화된 run에서만 표시합니다.

## Experiment Suite

`experiments/factory_policy_comparison/`은 6개 정책을 worker 3~8대와 5개 seed에서 비교합니다. Runner는 scenario, horizon, seed, worker config, HumanoidSim config와 사전 진단 fingerprint를 검사하고 run별 audit 결과와 mode/worker-count 통계를 HTML dashboard로 만듭니다.

## Compatibility

- Python 실행은 repository의 `.venv`를 권장합니다.
- HumanoidSim은 sibling repository를 editable install해서 최신 catalog를 사용합니다.
- `rolling_horizon_throughput_optimizer`에는 `ortools`가 필요합니다.
- 기본 `requirements.txt`는 factory 6-policy comparison에 필요한 simulation, OR-Tools, 집계, 정적 dashboard package만 설치합니다.
- LLM/OpenClaw/Knowledge Graph와 legacy Streamlit UI는 `requirements-optional.txt`로 분리했습니다.
- 기존 2D Replay artifact는 호환용으로 남지만 Hub의 지원 replay 진입점은 Replay Studio 3D입니다.
